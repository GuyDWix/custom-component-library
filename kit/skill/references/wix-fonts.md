# Wix catalog fonts you may use

Source: `wix-private/font-management` `packages/fonts-data/src/fonts-metadata/v1/metadata.json`, pulled 2026-11-25. Filter: open-licence providers (google, google-self-hosted, wix-madefor, open source) with `permissions: all`. Monotype and legacy fonts are left out: Wix licenses them, so codegen cannot load them from Fontsource.

Use the name exactly as written, e.g. `font-family: 'Bricolage Grotesque', sans-serif`. A family not on this list is a fail, even if it looks like one that is (Inter Tight, Barlow Condensed, Hanken Grotesk are not).
