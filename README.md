# Custom Component Library

Original ERC components built from concept descriptions, each with a recreate prompt, plus a showcase site (GitHub Pages).

- `components/<Name>/`: component code, manifest, recreate prompt
- `site/`: showcase app
- `contract/`: build contract and generation prompts
- `skills/component-craft/`: **start here to build or review a component** (quality bar, art-direction law, common misses, process, file contract, checklists)
- `scripts/`: `check-component.sh` (mechanical gate), `shot.sh` (captures), `build-prompts.sh` (PROMPT.md), `sync-skill.sh` (read-only codegen reference into `.skill/`)

Research, scoring and decisions live outside this repo, in the PM project ledger.
