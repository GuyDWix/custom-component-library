# Custom Component Library

Original ERC components built from concept descriptions, each with a recreate prompt, plus a showcase site (GitHub Pages).

- `components/<Name>/`: component code, manifest, recreate prompt
- `site/`: showcase app
- `scripts/`: `check-component.sh` (mechanical gate), `shot.sh` (captures), `build-prompts.sh` (PROMPT.md)

Research, scoring and decisions live outside this repo, in the PM project ledger.
